# What is Coven's Automation Toolkit (CAT)?
Coven's Automation Toolkit is an API module that provides framework and utilities for high-automation games using Midi-QOL. This module is intended for module developers and macro writers to use to make premade automations. This module does not provide premade automations, however this module is a dependency for other modules that do. However, CAT does provide the interface to apply and configure automations provided from premade modules. This interface is called the Cat Kit.

## The Cat Kit 
CAT adds a button to the title bar/3-dot menu of document sheets called the Cat Shield [CATSHIELD ICON HERE]. This button is used to access the Cat Kit, an interface to apply automations and configure available settings for those automations. The Cat Kit is available on Activities, Actors, Effects, Items, and Regions, and the features available vary by document type.

### On Items

[Picture of Title Bar on Tidy and 3 dot menu on core]

The Cat Kit on an Item Sheet's title bar will be colored based on it's status. Clicking it will open up the Item Medkit.<br>

[Picture of item cat kit]

The Catkit will show information about the item, if there's an available automation, if it is up to date, and allows you to choose which automation is applied.<br>
